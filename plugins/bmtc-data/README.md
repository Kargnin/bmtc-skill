# BMTC Data (Unofficial)

Ask AI agents about Bengaluru BMTC routes, directional stops, schedules, observed bus locations and predicted arrivals. This plugin reads Reclaim's documented public GTFS interfaces. It is independent of BMTC and Reclaim and is not an official transport service.

The skill checks each selected bus's GPS and prediction timestamps, keeps schedules separate from live observations, and explains when a match is uncertain or data is stale. It supports ordinary, Vajra, feeder and airport-route questions across the available network. A temporary tracking view can be generated by the host when useful; no permanent website or UI scaffold is included.

Execution requires Python 3.10+, curl, SQLite, timezone data and permitted HTTPS on macOS/Linux or an appropriate cloud runtime. No account, credential, hosted MCP service or background tracker is bundled. A package install does not itself grant network or script-execution access. If a host cannot execute the helper, it must say so rather than claim to have performed a live lookup.

Start with `skills/bmtc-data/SKILL.md`. Code is MIT licensed; upstream transit data retains its own terms. Read `DATA_SOURCES.md`, `PRIVACY.md` and `TERMS.md`. Report issues at https://github.com/Kargnin/bmtc-agent-plugin/issues without sharing private itineraries or credentials.
