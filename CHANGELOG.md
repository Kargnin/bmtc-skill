# Changelog

## 0.1.0 - 2026-11-21

- Initial standalone public Agent Skill, installable with `npx skills add`.
- On-demand route/stop/schedule and vehicle/arrival queries with shared caching.
- Per-vehicle freshness, overnight service-date and trip/stop matching checks.
- Disposable UI guidance, synthetic tests, portable ZIPs and maintenance instructions.
- Public distribution uses GitHub; no plugin-directory submission is required.
