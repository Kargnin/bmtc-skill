# Distribution status

Version 0.1.0 is prepared for public GitHub distribution with separate Codex and Claude Code marketplace manifests. Directory approval is not implied by these files.

| Surface | Distribution path | Requirement |
|---|---|---|
| Codex local clients | Public GitHub marketplace | Add marketplace and install `bmtc-data` |
| Claude Code | Public GitHub marketplace | Add marketplace and install `bmtc-data` |
| ChatGPT / Codex universal directory | Platform plugin ZIP submission | Verified developer identity, permitted publisher role, package scan/review and publication |
| Claude chat / Cowork directory | GitHub plugin-folder submission | Eligible paid Claude plan, connected GitHub push access, validation/review and publication |
| Cloud/mobile execution | Installed cloud-capable package | Host must support executing the helper with outbound HTTPS; no personal Mac is inherently required |

OpenAI package: `dist/bmtc-data-openai-0.1.0.zip`.
Claude package: `dist/bmtc-data-claude-0.1.0.zip`.
Claude directory source: `Kargnin/bmtc-agent-plugin`, plugin path `plugins/bmtc-data`, branch `main`.
